System Architecture & Routing

This document cleanly explains how the modernized FastAPI architecture elegantly handles requests, authentication, and AI routing.

1. The Modular Routing Pattern

Instead of mixing all backend code into a single massive file (or using legacy Django conventions), the application is broken down into clean, single-purpose routers inside the backend/routers/ directory:

  • backend/routers/auth.py: Exclusively handles Google One Tap and OAuth login flows.
  • backend/routers/tools.py: Exclusively handles the AI tools (Ollama, PDF parsing, text-to-speech, etc.).

In main.py, these routes are seamlessly attached to the main FastAPI app using the include_router syntax:

app.include_router(auth.router, prefix="/api/auth", tags=["auth"])
app.include_router(tools.tools_router, prefix="/api/tools", tags=["tools"])

2. Authentication (auth.py)

The auth.py router leverages Google's OAuth2 securely. When you log in, it verifies your Google token, checks the MySQL database (managed in backend/models.py), and provisions a secure JWT session token.

It explicitly routes the Google callback to exactly match the configured URL in your Google Cloud Console: /accounts/google/login/callback/.

3. Direct AI Integration (tools.py)

All AI requests hit tools.py. The fastest and most direct AI tool is the main chat. When you type in the search bar, it hits the /api/tools/chat endpoint which talks directly and instantaneously to your local Ollama server running llama3 natively on your hardware at localhost:11434. There is zero external network latency overhead.

4. Database Tracking (database.py & models.py)

The backend/database.py file holds the pure SQLAlchemy engine connection. Every time an AI tool finishes its job, the router injects a clean SQL commit:

new_data = ToolData(tool_name="Tool Name", data="User Request")
db.add(new_data)
db.commit()

5. Comprehensive File Overview

  • backend/main.py: The core FastAPI application entry point. It wires together all routers and mounts the static frontend.
  • backend/database.py: Sets up the SQLAlchemy engine and provides the get_db dependency to securely inject database sessions into routes.
  • backend/models.py: Defines your strict MySQL database schema using Python classes (e.g., User, ToolData).
  • backend/routers/auth.py: Manages OAuth and Google One Tap credential verification to ensure secure user sessions.
  • backend/routers/tools.py: The engine of the AI platform. It contains every API endpoint for your tools, processing inputs (like connecting to Ollama) and returning JSON data to the frontend.
  • frontend/index.html: The structural DOM of the interface, rendering the beautiful modern white UI, One Tap popup, and tool grid.
  • frontend/css/style.css: Contains all design logic, the visual grid background, typography scaling, and glass-like shadows.
  • frontend/js/app.js: The nerve center of the frontend. It intercepts form submissions (like typing in the main chat bar) and orchestrates fetch requests to the backend APIs.
