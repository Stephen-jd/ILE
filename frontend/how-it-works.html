ILE PROJECT GUIDE

How it works

ILE is a ten-tool workspace. The page is the launcher; each tool opens only when selected. Small file and text operations run in the browser or FastAPI, while AI analysis runs through Ollama on your computer.

Tools included

Resume AnalyzerPDF resume and job description, analyzed with Ollama.
Text to ImagePrompt sent to an online image-generation service.
Code ExplainerCode explanation generated by the local Ollama model.
MD to HTMLBasic headings, paragraphs, and lists converted in the browser.
BeautifierDraft rewritten by the local Ollama model.
PDF to TextSelectable PDF text extracted by pypdf.
Text to AudiogTTS generates speech using the selected language.
Image ResizeImage resized locally in your browser; it is not uploaded.
Hyperlink GeneratorCreates a safe, downloadable HTML link in your browser.
URL ShortenerSaves long URLs in SQLite and redirects through the local app.

Requirements

  • Python 3.10 or newer and the packages listed in requirements.txt.
  • Internet access for gTTS speech generation and online text-to-image generation.
  • Ollama running locally with the configured model installed for Resume Analyzer, Code Explainer, and Beautifier. The default model is llama3.2.
  • Optional Google OAuth credentials in client_secret.json for Login and One Tap. The tools themselves do not require login.
  • For Google One Tap, authorize http://127.0.0.1:8000 as a JavaScript origin in the Google Cloud OAuth client and sign in to a Google account in the browser.
  • PDFs must contain selectable text; scanned image-only PDFs need OCR, which is not included.

Set ILE_OLLAMA_MODEL to use another installed model, or ILE_OLLAMA_URL if Ollama runs at a different address.

Run the app

  1. Install dependencies: python -m pip install -r requirements.txt
  2. For AI tools, start Ollama and install a model, for example ollama pull llama3.2.
  3. Start ILE with python main.py.
  4. Open http://127.0.0.1:8000.
URL Shortener → FastAPI → SQLite → redirect
