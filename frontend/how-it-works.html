How ILE works

ILE is a simple local AI tool app. The user types text, chooses a language, and the server converts it into speech using Google Text-to-Speech.

Frontend User types text and chooses language in the page.
JavaScript Browser sends a POST request to the API with the selected text and language.
Backend FastAPI receives the request and calls Google Text-to-Speech.
Audio Output The browser receives audio and plays it automatically.
1

User opens the app

The browser loads the main page and shows the text area, language dropdown, copy button, and generate audio button.

2

User enters text

The user pastes or types the text they want to hear. They can also copy the text before playing it.

3

User chooses language

The selected language controls the voice. Example: English, Hindi, Spanish, French, German, and more.

4

Frontend sends the request

The JavaScript function sends a JSON payload to the backend route /api/tools/text-to-audio.

5

Backend generates audio

The FastAPI route receives the text, calls gTTS with the chosen language, and converts it into an audio stream.

6

Browser plays the result

The audio file is returned to the browser and the HTML audio player starts playing it right away.

POST /api/tools/text-to-audio
{
  "text": "hello welcome to ILE",
  "lang": "en"
}
7

Architecture summary

  • Frontend: simple HTML + JavaScript page
  • Backend: FastAPI server handles requests
  • TTS engine: gTTS converts text to speech
  • Database: SQLite for local app data
  • Result: clean and easy-to-understand flow
